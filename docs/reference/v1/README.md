# modetective β（モデル探偵（仮称）の進行アプリ）

## 置き方

このフォルダの中身を、そのまま `https://m-miura.jp/pt/modetective/` に置きます。

```
modetective/
  index.html
  app.js
  style.css
  data/共有用_テーマカード集.md   … お題データ
```

`https://m-miura.jp/pt/modetective/` を開くと、ホーム（GM用）が出ます。パソコンのファイルを直接開いても動きません（お題データを読み込めないため）。

## お題の差し替え

`data/共有用_テーマカード集.md` を、新しい共有用テーマカード集で置き換えます。書き方（`## T01　★` の見出し、`- **場面**：…` の箇条書き、`## 3-1`／`## 3-2` の場面リストの表、`## 4-1`／`## 4-2` の対応表）を保てば、そのまま読めます。ファイル名を変えるときは、`app.js` の先頭にある `CARD_FILE` を書き換えます。

ゲームの途中でお題データを差し替えると、そのゲームのURLが開けなくなることがあります（カードが見つからない場合）。

## 変えられる設定（app.js の先頭）

- `MAX_REDRAW`：引き直しの回数（いまは2）
- `MAX_GROUPS`：グループ数の上限（いまは10）
- `PASSWORDS`：合言葉の候補

## しくみ

- 画面どうしは通信しません。ゲームの設定と配ったカードは URL に入っています。
- フェーズは、GMが伝える**合言葉**で進みます（調査→推理、推理→解決編）。
- チームが確定したカードは、**事件番号**（4文字）で相手チームとGMに伝えます。
- 参加者の進み具合はブラウザに覚えさせるので、再読み込みしても戻りません。
- QRコードは外部ライブラリ（cdnjs）で表示します。読み込めないときは URL だけを表示します。
