# modetective 設計メモ（2026-11-05）

モデル探偵の進行を案内・制御する Web アプリの設計です。置き場所は `https://m-miura.jp/pt/modetective/` です。

## 1. 方針

- **β版であることを明示する**。画面の上部とブラウザのタブに「modetective β」と出し、ホームの下に「β版：試作中です。内容や動きは変わることがあります」と書く（ゲーム名は「モデル探偵（仮称）」として併記）。

- **静的ファイルだけで動かす**（HTML／JavaScript／CSS）。データベースもサーバ側の処理も使わない。
- 画面どうしで情報を共有しないので、次の3つで進行をそろえる。
  1. **ゲームURL**：GMが設定するとURLができる。設定と最初に配ったカードはURLに入れる（読めないように変換する）。GMはこのURLを会議ツールのチャットで配る。
  2. **合言葉**：参加者が次のフェーズへ進むには、GMが口頭で伝える合言葉を入れる。
  3. **事件番号**：チームがカードを確定すると、アプリが短いコード（例：Q7XK）を出す。チームはそれを相手チームとGMに伝える。
- 複雑なこと（モデリング、タイマー、回答の記入、採点）は Balus や画面の外で行う。アプリは流れの案内と、カードの提示・公開だけをする。

### 見た目

- **全体をレヴィカラー調にする**：メインはティール（#0097A7）、差し色は黄（#FFBC1B）。
  - ティール：見出し、上部のバー、ボタン、Balus の指示の枠
  - 黄：β版の表示、合言葉、事件番号、いま押すべきボタンなど、目を引きたいところ
  - 地の色は白と薄いティールにし、文字は濃いグレーにする
- 探偵の要素（ルーペのアイコン、「事件番号」「解決編」などの言葉）は控えめに入れる。

## 2. ファイル構成

```
modetective/
  index.html          … 画面はこの1ページ。表示を切り替える
  app.js              … 処理
  style.css           … 見た目
  data/
    共有用_テーマカード集.md   … お題データ。資料の共有用ファイルをそのまま置く
```

- お題を差し替えるときは、`data/` のmdを置き換えるだけでよい。ファイル名は `app.js` の先頭で変えられる。
- mdの読み方：
  - `## T01　★` と `## K01　★　日常系` の見出しをカードとして読む。その下の「場面」「目的」「お題」「結論の形」「目的の判定メモ」「目的の選択肢」「補足」を箇条書きから読む。
  - 「3-1」「3-2」の表は、モードごとの場面の選択肢リストとして読む。
  - 第4部の対応表と、各カードの「補足」は、組み合わせてはいけないカードを決めるのに使う。
- 参加者のブラウザでは、選んだチームや進んだフェーズを覚えておく（再読み込みしても戻らないようにするため）。覚えられないブラウザでも、使えなくなることはない。

## 3. 画面と流れ

| # | 画面 | 見る人 | 内容 | 次へ進む条件 |
|---|---|---|---|---|
| 0 | **ホーム** | GM | 共通カード／個別カード、シナリオ／聞き込み、目的の答え方（選択肢あり／なし）、GMも参加するか、グループ数（1〜10）を選び、「ゲーム開始」を押す | ― |
| GM | **GM画面** | GM | ゲームURL（とQRコード）、各フェーズの合言葉、最初に配ったカードの一覧（答え。GMも参加する場合は伏せて事件番号だけ）、フェーズごとの台本（GMが言うこと）と時間の目安、事件番号を入れるとカードがわかる欄 | ― |
| 1 | **チーム選択** | 参加者 | グループ（G1, G2…）と A／B を選ぶ | ボタン |
| 2 | **カード提示** | 各チーム | 配られたテーマカードを表示する。気に入らなければ「引き直す」（2回まで、ランダム）。「これでいく」で確定すると事件番号が出る。共通カード方式では引き直しはできない | 確定 |
| 3 | **調査フェーズ** | 各チーム | 確定したカードと事件番号を表示する（モデリングとタイマーは Balus で行う）。モデリングのルールも表示する。聞き込みモードなら、聞き込みの進め方と注意も表示する | 合言葉 |
| 4 | **推理フェーズ** | 各チーム | 相手チームの事件番号を入れると、相手カードの「目的の選択肢」（選択肢ありの場合）が出る。あわせて場面の選択肢リスト（そのモードの分）と、回答の記入項目のひな形（コピーして Balus などに貼る）を表示する。自分のカードは折りたたんで見られる | 合言葉 |
| 5 | **解決編** | 各チーム | 自分と相手のカードの場面・目的を並べて公開する。配点の早見表と判定の境界（その場面の行）も表示する。採点そのものは画面の外で行う | ボタン |
| 6 | **振り返り** | 全員 | 全体共有で話す切り口の一覧（聞き込みモードの切り口も含む）。「次のセット」でGMは新しいゲームを作る | ― |

### Balus での作業の指示

Balus を使う場面では、画面にはっきり指示を書く（目立つ枠で表示）。

| 画面 | 表示する指示 |
|---|---|
| 調査フェーズ | 「Balus 上でモデリングしながら、このお題について話し合ってください。」「結論は、モデルとは別の場所に書いてください（場所はGMの案内に従ってください）。」「モデルには、場面の言葉、目的の文、お題の問い、結論を書かないでください。」 |
| 調査フェーズ（聞き込みモード） | 上に加えて「はじめの5〜8分で聞き込みをしてから、Balus でモデリングを始めてください。」 |
| 推理フェーズ | 「Balus で相手チームのモデルを開いて、読み取ってください。モデルは見るだけで、編集しないでください。」「回答（場面・目的・結論）は、下のひな形を使って、GMが案内する場所に書いてください。」 |
| 解決編 | 「Balus で両チームのモデルを開き、答えと見比べてください。」 |
| 振り返り | 「GMが画面共有する Balus のモデルを見ながら話し合いましょう。」 |
| GM画面の台本 | 各フェーズで、Balus のどこを開いてもらうか、何を見せるかを書く |

時間の管理（タイマー）も Balus で行うので、アプリにタイマーは置かない。画面には「時間は Balus のタイマーで確認してください」と書く。

## 4. カードの配り方

- **個別カード方式**：グループごとに、AとBの**カードの山**（引き直し用の候補を含む）を作る。Aの山のどのカードとBの山のどのカードを組み合わせても、組み合わせ禁止にならないように作る。そうすれば、両方のチームが引き直しても組み合わせ禁止が起きない。
- **共通カード方式**：全グループのAに同じカード、Bに同じカードを配る。引き直しはできない（変えたいときは、GMがホームで作り直す）。
- **組み合わせ禁止**：同じ場面、第4部の対応表で同じ行に入る場面どうし、カードの「補足」に書かれた組み合わせ。
- GM画面に出す答えは、最初に配ったカードの分です。引き直したチームのカードは、事件番号で確かめる。

## 5. 事件番号と合言葉

- **事件番号**：カード番号とゲームごとの乱数から作る4文字（読み間違えやすい文字は使わない）。番号を見ても場面はわからない。別のゲームの番号や打ち間違いは、エラーとして弾く。
- **合言葉**：ゲームごとに決まり、GM画面に出す。「調査フェーズ→推理フェーズ」と「推理フェーズ→解決編」の2か所で使う。探偵にちなんだ言葉（例：ルーペ、ワトソン）にする。
- どちらも、のぞき見を防ぐ程度の仕組みです。本気で調べれば破れる（紳士協定が前提）。

## 6. 決めたこと（2026-11-05 三浦）

- アプリ名：modetective
- 静的ファイルだけで作る
- フェーズは合言葉で進める
- カードはアプリが配り、チームが引き直せる（2回まで、ランダム）。「これでいく」で確定する
- 確定したカードは事件番号で相手チームとGMに伝える
- 共通カード方式では引き直しはできない
- お題データは共有用テーマカード集をそのまま読む

- アプリ名に β 版であることを明示する
- Balus を使う場面では、「Balus 上でモデリングしてください」などの指示を画面に書く
- 全体をレヴィカラー調にする（ティール #0097A7、差し色 黄 #FFBC1B）
- GMもゲームに参加できる。ホームで「GMも参加する」を選ぶと、GM画面では最初に配ったカード・場面・目的を伏せ、事件番号だけを表示する（事件番号からカードを調べる欄は、警告つきで折りたたむ）
- 推理フェーズの回答のひな形は、場面・目的・結論の3項目だけにする（理由は解決編の発表のときに口頭で説明する。2026-11-05 変更）
- 配点は、場面2点・目的4点・結論4点（1方向10点、グループ20点。2026-11-05 変更）

## 7. 実装のときに決めること（こちらで決めて、あとで報告する）

- 細かい見た目（配色は下の「見た目」のとおり。PCとスマホの両方で読めるようにする）
- QRコードの表示（外部のライブラリを使う。読み込めない環境ではURLだけを出す）
- 1セットで使うモードは1つだけ（シナリオと聞き込みを混ぜる遊び方には、当面は対応しない）
