# モデル探偵（仮称） テーマカード集

モデル探偵で使うテーマカード、場面の選択肢、採点用の対応表です（試作版）。ルールは別ファイル『ルールと進行』を見てください。

## この文書の使い方

- **テーマカード**：モデリングフェーズで各チームに提示するカードです。カードの内容はすべて見せてかまいません。お題のモードごとに分けています。
  - 第1部：シナリオモードのカード（T01〜T28）。ゲーム設計側が場面や設定を用意したもの
  - 第2部：聞き込みモードのカード（K01〜K20）。チームの中の聞き込み対象の人の、実際の経験や事実をもとにするもの
- **場面の選択肢リスト**（第3部）：読み取りフェーズで全チームに見せます。モードごとに1つずつあります。
- **目的の選択肢**（各カード）：目的を選択肢から選ぶ場合に、読み取りフェーズで、相手チームのカードの分だけを見せます。
- **紛らわしい選択肢の対応表**（第4部）：採点で判定が割れたときの基準です。

### カードの項目

| 項目 | 内容 |
|---|---|
| 場面 | 読み取りフェーズで相手チームが当てる場面（一言）。選択肢リストに必ず含まれる |
| 目的 | 読み取りフェーズで相手チームが当てる、モデリングの目的 |
| お題 | モデリングフェーズで、チームがこれを読んでモデリングする文章。場面と目的の要素を含み、チームが出すべき結論に対する問い（**太字**）を含む |
| 結論の形 | チームが書く結論がどんな形になるかの目安（列挙、特定、選択など） |
| 目的の判定メモ | 目的を選択肢なしで答える場合に、採点で「一致」とみなす言い方の例 |
| 目的の選択肢 | 目的を選択肢から選ぶ場合に、読み取るチームに見せる5択。正解（カードの目的）と、紛らわしい4つを含む。場面の一言は含めない |
| 難易度 | ★〜★★★ |
| 系統 | 聞き込みモードのカードだけにある。日常系（家や暮らしの話）か仕事系（職場の話）か |

### 提示のしかた

1グループのAチームとBチームには、**場面が違い、第4部の同じ行にも入らない2枚を組み合わせてください。** 近い場面が組み合わさると、自分のカードから相手チームの場面を推測できてしまいます。聞き込みモードでは、各カードの「補足」に、組み合わせないカードを書いています。

1セットの中では、全チームで**同じモード**のカードを使うのが基本です。モードを混ぜる場合は、第3部の2つのリストを合わせて見せます。

提示のしかたには2つの方式があります（詳しくは『ルールと進行』5章）。

- **共通カード方式**：全グループのAチームに同じカード、Bチームに同じカードを提示します。同じお題から出てくるモデルの違いを比べられ、得点も公平になります。
- **個別カード方式**：グループごとに違うカードの組を提示します。いろいろなテーマのモデルが出てきます。

# 第2部 テーマカード（聞き込みモード・20枚）

聞き込みモードのカードです。お題の具体的な中身は、チームの中の**聞き込み対象**の人から聞き出します（進め方は『ルールと進行』5章フェーズ2）。チームが1人のときは、自分自身が聞き込み対象になります。

- **目的の選択肢**（選択肢ありの場合）：使う道具を選ぶ／予定の抜けやダブりの原因を探る／予定の優先順位を決める／空き時間を増やす／予定を入れるルールを新しく作る

## K15　★★　仕事系

- **目的**：探しているものが見つからない原因を探る
- **お題**：聞き込み対象の人に、最近「あのファイルどこだっけ」と探したことを思い出してもらい、ファイルを作ってから保存し、また探すまでの流れを聞き出してください。**見つからなかった原因は何か？**
- **結論の形**：原因の特定
- **目的の判定メモ**：「見つからない理由を知る」「保存のしかたの問題を見つける」は一致とする
- **目的の選択肢**（選択肢ありの場合）：保存する場所のルールを新しく作る／探しているものが見つからない原因を探る／いらないものを処分する／名前の付け方を決める／保存する容量を増やすべきか判断する

## K16　★★★　仕事系

- **結論の形**：原因の特定

## K20　★★★　日常系

# 第4部 紛らわしい選択肢の対応表（採点用）

紛らわしさは2種類あります。

- **題材が近い**：言葉やモノが似ていて、モデルの要素名だけでは見分けにくいもの
- **形が似ている**：題材は違うが、モデルにすると同じ形（流れ＋待ち、分担表、比較など）になりやすいもの

「判定の境界」は、回答が紛らわしい選択肢だったときに、正解とするかどうかを決める目安です。**境界に書かれていない選択肢は不正解とします。**

## 4-2 聞き込みモード

聞き込みモードでは、聞き込みの中身によって、モデルの題材がカードの場面から少しずれることがあります。「正解扱いとしてよい」かどうかは、モデルを描いたチームの結論とモデルの中身を見て、ファシリテーターが判断します。

| 正解の場面 | 題材が近い | 形が似ている | 判定の境界 |
|---|---|---|---|
| 朝の支度（K01） | 通勤、テレワーク | 夜の過ごし方（時刻の流れ） | 移動が中心のモデルなら、通勤も正解扱いとしてよい。テレワークは不正解 |
| 週末の過ごし方（K02） | 趣味の時間、昼休みの過ごし方 | 仕事の1日（時間の流れ） | 趣味の時間は不正解（週末全体の流れが描かれるはず） |
| メールの処理（K03） | チャットの返信 | 仕事中の割り込み | チャットが中心のモデルなら、チャットの返信も正解扱いとしてよい |
| 資料づくり（K04） | 議事録づくり、年賀状づくり | 仕事の依頼（頼まれてから仕上げるまで） | 聞き込みで挙がった資料が議事録なら、議事録づくりも正解扱いとしてよい |
| 会議の準備（K05） | 日程調整、議事録づくり、会議室の予約 | オンライン会議 | いずれも不正解（会議の前にやることの全体が描かれるはず） |
| 出張の手配（K06） | 経費精算、旅行 | 承認の手続き（申請の流れ） | 経費精算は不正解（精算だけでなく、行く前の手配からの流れか）。旅行も不正解 |
| 仕事中の割り込み（K07） | チャットの返信、テレワーク | 仕事の1日 | 仕事の1日は不正解（割り込みが描かれているかで区別） |
| 仕事の依頼（K08） | 業務の引き継ぎ | 資料づくり | 業務の引き継ぎは不正解（担当がまるごと移るのか、1つの頼みごとか） |
| ツールの導入（K09） | テレワーク | スケジュール管理 | 不正解 |
| 夜の過ごし方（K10） | 昼休みの過ごし方、週末の過ごし方 | 朝の支度（時刻の流れ） | 不正解（その日の活動を終えてから寝るまでの流れかで区別） |
| 日用品の買い足し（K11） | 大掃除、ゴミ出し | スケジュール管理（気づく→書く→確認） | 不正解 |
| 旅行（K12） | 修学旅行 | 出張の手配（準備から片付けまで） | 修学旅行は不正解。出張の手配は、仕事での移動が描かれていれば出張の手配 |
| 新しい習慣（K13） | ジム通い、子どもの宿題 | ― | 聞き込みで挙がったのがジム通いそのものなら、ジム通いも正解扱いとしてよい。子どもの宿題は不正解 |
| スケジュール管理（K14） | 日程調整、会議室の予約 | 日用品の買い足し | 不正解（日程調整は相手との調整、スケジュール管理は自分の予定の受け取り・記録・確認） |
| ファイルの整理（K15） | 大掃除 | 資料づくり | 不正解 |
| 仕事の1日（K16） | テレワーク、仕事中の割り込み | 週末の過ごし方 | 不正解（1日全体の時間の使い方が描かれるはず） |
| チームの情報共有（K17） | 議事録づくり、チャットの返信、業務の引き継ぎ | ― | 不正解（人と人のあいだの伝わり方が描かれるはず） |
| 承認の手続き（K18） | 休暇の申請、経費精算 | 出張の手配 | 聞き込みで挙がった申請が休暇なら休暇の申請、経費なら経費精算も正解扱いとしてよい |
| オンライン会議（K19） | 会議の準備、議事録づくり、会議室の予約 | ― | 会議の準備は不正解（会議の前の準備か、会議の始まりから終わりまでか） |
| 家事の分担（K20） | 大掃除、ゴミ出し、弁当づくり | シフト表づくり | 不正解（1週間の家事全体と、その担当が描かれるはず） |

モードを混ぜたときは、次の境界も使います。

- 旅行（K12）に対して「家族旅行」と答えた場合は、家族と行った旅行なら正解扱いとしてよい。
- 家族旅行（T17）に対して「旅行」と答えた場合は不正解（候補の比較が描かれているはず）。
